# Fixtures

Every file starting with `fake_` is invented by hand for tests and examples.
None of them come from a real video. Real outputs written by `understanding.run` should not be committed.

- `fake_media.json` - example media.json (ingestion output)
- `fake_understanding_transcript.json` - example understanding.json on the transcript route
- `fake_understanding_vision.json` - example understanding.json on the vision route
